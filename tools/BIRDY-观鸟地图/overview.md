# BIRDY-观鸟地图 使用手册生成概述

## 完成内容

基于工作目录代码（`birdy_track_map/gui.py` 等），生成了一份面向最终用户的操作手册，聚焦于软件操作而非技术实现。

## 交付物

| 文件 | 说明 |
|------|------|
| `manual_assets/user_manual.html` | 可交互预览的 HTML 使用手册 |
| `manual_assets/manual_full.png` | 完整手册长截图（便于打印、分享、插入文档） |

## 手册结构（以图为主）

1. **启动软件** — 主界面输入区标注：鸟图目录、GPX 文件、勾选框
2. **设置地理位置** — 地点输入、查询按钮、省/市解析结果标注
3. **配置地图选项** — 去重半径、底图样式、海拔剖面、时区、Logo 标注
4. **配置高德 API Key** — 首次使用配置入口标注
5. **预览与生成** — 预览按钮、正式生成按钮、日志区标注
6. **输出结果** — 2K 竖屏手机示意图（标题、轨迹、鸟种标注点、海拔剖面）
7. **常见问题速查** — 底图空白、鸟点少、生成慢、配置保存等

## 设计特点

- 采用 CSS 高保真模拟 PyQt5 Windows 原生界面风格
- 橙色圆点数字 + 文字标注直接指向操作位置
- 每步配有蓝色提示框（Tip）补充注意事项
- 无代码、无文件结构说明，纯操作导向

常见问题速查

Q：底图空白或提示 no_key / fallback？
A：检查是否已配置高德 API Key，并确认网络可访问高德地图服务。

Q：地图上鸟点很少或没有？
A：确认照片 EXIF 包含拍摄时间；检查 GPX 与 EXIF 时区设置；可勾选「补充使用照片 EXIF 中的 GPS」。

Q：生成速度很慢？
A：正式导出需要下载底图并绘制全部标注，属于正常现象。先用预览模式快速确认参数。

Q：如何保存我的常用设置？
A：软件会自动将当前界面参数保存到同目录的 config.json 文件中，下次启动自动恢复。

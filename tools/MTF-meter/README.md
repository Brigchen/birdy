# MTF-meter

独立 GUI：**比较不同镜头的成像效果**。不接入 Birdy 主程序，本目录即可运行。

---

## 功能

### 1. ISO 12233 标准测量

对标板（斜边约 5°）批量照片：

- 只在 **左 / 右 / 上 / 中下** 四区定位约 5° 斜边（L/R 黑斜块、上方斜条、中心偏下斜方块），避开中央圆环与四角星形图；再映射回原图按 ISO 12233 斜边 SFR 计算 **MTF50 / MTF30 / MTF10**（cycles/pixel）、**过锐峰值**与 **中心/边比**
- 若 EXIF 含焦平面分辨率，同时给出 **lp/mm**
- 读取镜头、焦距、ISO、光圈、机身
- 按勾选的字段**自动分组比较**（中位数 / 均值）
- 每测完一张即刷新表格，可随时**中止**并保留已测结果

### 2. 同场景相对比较

对同一目标、不同镜头拍的照片：

- 按**拍摄时间间隔**、**子文件夹**或 **EXIF 镜头类型**划分场景
- 有可用斜边时用 MTF50，否则用梯度能量（Tenengrad）
- 组内最优为 **1.00**，其余为相对值
- 跨场景汇总各镜头相对分与平均名次

## 快速开始

```bat
python -m pip install -r requirements.txt
MTF.bat
```

macOS / Linux：

```bash
python -m pip install -r requirements.txt
chmod +x start.sh
./start.sh
```

界面与 Birdy 主程序风格接近（顶栏标题、白底卡片、绿色主按钮），但是独立窗口。图表使用系统中文字体；左侧汇总表小字号、列超出时可横向滚动。文件表列出 MTF50/30/10、过锐峰值与中心/边比，过锐偏高会标橙。点击右侧文件表，左下角显示该照片与斜边测量框（绿=中下斜方块，橙=上/左/右）。

结果可导出 **Excel**（`.xlsx`）：默认保存到照片文件夹，文件名为「文件夹名_年月日_编号」。含文件明细与**分组中位**两个工作表。

---

## 拍摄建议

- **标板**：ISO 12233 或同等斜边卡，边与画幅成约 5°，对焦准确、关闭过强锐化便于比较
- **同场景**：脚架、同一距离与构图，尽快换镜头连拍；也可按子文件夹划分，或按 EXIF 镜头类型把同型号照片归为一组

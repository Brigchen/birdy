鸟图智慧仓储（Birdy）

一页上手 · 拍鸟照片自动筛图、认种、归档、加水印、出行迹图 · 版本 2.0.62（2026-08-22）

① 第一次打开（只需做一次）

  1. 安装 Python 3.8+，在项目根目录（含 src 文件夹）打开终端，执行：
    pip install -r requirements.txt
  2. 若从 GitHub 下载源码，再执行：git lfs pull（拉取鸟体检测与识种模型，约 200 MB）
  3. 双击 start_gui.bat（Windows），或运行：python src\birdy_gui.py

不用申请任何账号也能完成：连拍筛选 → 鸟体检测 → 本地识种 → 按物种分文件夹。只有需要「地名写进照片 / 轨迹图高德底图 / 云端识种」时才填 API Key（见下表）。

② 每次处理（三步）

  1. 图片文件夹：选本次要处理的鸟照所在目录。
  2. RAW+JPG（相机同录 RAW+JPEG 时）：选「仅 JPG」或「JPG + 复制 RAW」（筛选后 RAW 进 Screened_raw_images/）。
  3. 输出根目录（建议填写）：例如 D:\birdy\output。程序会自动在下面生成以本次文件夹命名的子目录。
  4. 在左侧卡片勾选需要的功能，点 「开始处理」。右侧可看进度与日志。

③ 处理完会得到什么

输出位置（在输出根目录下）内容
screened_文件夹名/连拍筛选后保留的照片（Screened_images）
classification_文件夹名/按物种分好的归档目录
reports/轨迹图 PNG、观鸟记录导出文件等

④ 常用功能怎么开

想做什么在界面里
连拍里只留最清晰几张「连拍筛选」→ 勾选「加入主流程」；保留比例按本组总张数（快速模式也如此，0.1 即约 10%，不是 1/3 再乘 0.1）
自动认种并分文件夹「物种识别」→ 勾选「加入主流程」
照片上加时间/地点/物种水印「水印生成」→ 勾选「加入主流程」或单独点生成
生成观鸟行迹地图「轨迹图生成」→ 准备 GPX + 鸟图目录 →「预览」或「单独生成并保存 PNG」；标题地点优先取「水印生成 → 人工地点」
导出 eBird / 观鸟记录中心表格「观鸟记录导出」→ 需先有分类归档目录；导出成功后可点链接直接打开 CSV / Excel；「累计只数」旁「设置」可调分窗时间与距离
连拍做成动图或 MP4「动图生成」→ 定点或跟踪 → 首图标定点+裁剪区 → 后续帧用鸟体检测+卡尔曼自动跟踪（漏检再模板匹配）→ 传播中也可翻页单击标定点（裁剪区按首图相对位置跟随，再翻页锁定；传播只跳过锁定页）→ 勾选自动曝光并调强度 → 选 WebP 或 MP4（默认 2 张/秒）。导入图片后在相片目录生成同名 .birdy-burst.json 项目
手持视频去抖、裁剪、保留原声「水印与分享」→「视频裁剪」；Windows 克隆后 git lfs pull 含 bin/ffmpeg.exe

⑤ API Key（按需，可后填）

功能要不要 Key配置文件（GUI 里可打开）
连拍 + 本地识种不需要—
地名 → GPS、水印地点高德 Keysrc/amap_api_config.json
轨迹图高德底图高德 Key同上

⑥ 遇到问题

  • 模型报错 / 文件很小：在项目根目录再执行 git lfs pull。
  • RAW 照片：尽量先转成 JPG，或确认已安装 rawpy（见 requirements.txt）。
  • 详细安装与许可：见同目录上级 安装说明.md、README.md。
  • 仅做轨迹图、不要主程序：可用 tools/BIRDY-观鸟地图/ 独立工具（无需高德 Key）。
